Logger32-SCP

Callsign suggestions for Logger32.

Logger32-SCP works alongside Logger32 and uses Logger32’s own DX Cluster spot feed. As you type in Call, it searches a local callsign database and displays matching and similar callsigns.

Designed to stay beside your log

  • Start automatically through Logger32: Tools → Utility program setup → select Logger32-SCP.exe → enable Autostart.
  • Receive DX Cluster suggestions directly from Logger32; no second cluster login is needed.
  • Closest suggestions first, with remaining matches following in order of similarity.
  • Click a suggestion to transfer it, or press Space in the logger’s Call field to accept your entry.
  • Import ADIF to add callsigns without changing your logged contacts.
  • Automatically save a new cluster callsign after three received spots within 24 hours; Space can save it sooner.
  • Six interface languages and an included six-language guide.
  • Automatic program updates with your approval, preserving personal callsigns, databases and settings.

Getting started

  1. Download the full Share.zip from the latest GitHub release.
  2. Extract the entire ZIP to a permanent folder with English characters throughout the path, for example C:\Logger32-SCP. Do not run inside the ZIP.
  3. Logger32 must already be installed. In Logger32, choose Tools → Utility program setup, select Logger32-SCP.exe from the extracted folder and enable Autostart.
  4. Read README.txt or open Help in Logger32-SCP for the complete guide.

When upgrading manually, keep your existing databases, personal callsigns, exclusions and settings. Follow the upgrade instructions on the release page.

Questions

Is it free?

Yes. Logger32-SCP is free to download and use. You do not need a GitHub account to download a release.

Does it change my contacts?

ADIF import adds callsigns to the suggestion database. It does not alter your existing logged contacts.

Can I share it with another radio amateur?

Share the official release-page link so they can download the current clean package with the guide. Do not share your personal settings or callsign data files.
